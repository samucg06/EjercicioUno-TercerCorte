# EjercicioUno-TercerCorte

## 🧩 Design Underground System
Sistema que registra viajes en metro almacenando entradas y salidas de usuarios para calcular el tiempo promedio entre estaciones. Usa estructuras hash para realizar operaciones y consultas de forma eficiente.

## 🏧 Design ATM Machine
Simula un cajero automático que permite depositar y retirar dinero con diferentes denominaciones de billetes. El retiro sigue una estrategia voraz, priorizando siempre los billetes de mayor valor.

## 💰 Design Auction System
Sistema de subastas donde los usuarios pueden agregar, actualizar o eliminar ofertas sobre un producto. También permite consultar rápidamente cuál es el mejor postor en cada artículo.

## 📅 Meetup
Calcula la fecha exacta de una reunión a partir de un día de la semana y una ocurrencia específica dentro de un mes, como primero, segundo, teenth o último.

## 🕒 Clock
Implementa un reloj sin fecha que permite sumar o restar minutos, normalizar la hora dentro de un ciclo de 24 horas y comparar si dos relojes representan el mismo momento.
